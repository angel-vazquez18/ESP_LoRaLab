The enclosure was created directly through the native Codex FreeCAD MCP tools.
No external modelling script or custom FeaturePython proxy is required to edit it.

native-build-operations.json records the main native feature-construction calls.
It is an audit record, not a standalone replay script. Its prerequisites are:
  LoRaEnclosure document; Parameters spreadsheet populated from parameters.csv;
  BaseBlank Part::Box driven by B45/B46/B44 at (-B4-B5,-B4-B5,0);
  RoundedBaseBlank Part::Fillet on BaseBlank vertical edges 1,3,5,7,
  with each fillet radius linked to Parameters.B42.
All three printable outputs remain native, linked parametric FreeCAD features.

ReferencePCB and Reference* envelopes provide visual and clearance aids only.
They are simplified native primitives; they are not imported component models.
The manufacturer Heltec/OLED upper extent is retained; amplifier and microphone
thicknesses remain provisional. Export only the three printable final objects.

Parameter validity includes positive dimensions, sufficient component clearance,
and CornerRadius > Wall + FitGap + LipThickness (current 4.5 > 3.9 mm).
Reducing dimensions past feature or component limits can make the model invalid.
The CSV is a snapshot; editing it does not automatically update the saved model.
Edit labelled values in the saved document's Parameters sheet instead.
